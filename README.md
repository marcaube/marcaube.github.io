# marcaube.ca

Source code of my [website](http://marcaube.ca) using [Zola](https://www.getzola.org/).


## Usage

Install Zola from https://www.getzola.org/documentation/getting-started/installation/

```bash
zola serve
```

Then go to [http://localhost:1111](http://localhost:1111)

## Building

```bash
zola build
```

The static site will be generated in the `public` directory.
